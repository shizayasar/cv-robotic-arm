# cv-robotic-arm
3D-printed robotic arm that mirrors your hand in real time using Python, OpenCV, and MediaPipe hand tracking, with servos driven through an Arduino.

## Hardware
- Arm design: [Humanoid Robotic Hand](https://www.thingiverse.com/thing:2269115) by grossrc on Thingiverse
- Printed on a Bambu Lab A1 (sliced in Bambu Studio), with my own tuned settings for wall count, infill, supports, and print orientation
- Servo motors controlled by an Arduino
